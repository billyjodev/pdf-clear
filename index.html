PDF Document Viewer

📄 PDF-Clear

Select, erase, and fill PDF regions — 100% browser-based, no server upload

📖 How to Use

  1. Click "Select PDF" to load a file
  2. Choose a fill color mode (Dominant/Border/Custom)
  3. Left-click drag on the PDF to select regions (red box)
  4. Click "Apply" to confirm selections
  5. Download as PDF or PPT

📖 사용 방법

  1. "Select PDF" 버튼으로 파일 열기
  2. 채우기 색상 모드 선택 (Dominant/Border/Custom)
  3. 좌측 클릭 드래그로 영역 선택 (빨간 박스)
  4. "Apply" 버튼으로 선택 적용
  5. PDF 또는 PPT로 다운로드

✅ All processing happens locally in your browser
